{% comment %} Pinewood page header. Two layouts, chosen automatically: - Breadcrumb style (default) — a small breadcrumb trail above a plain title. Used when no `icon` is given. - Icon-box style — a bordered banner with an icon box, title, description, and right-aligned actions. Used when `icon` is given. This is the consolidated replacement for the ≥5 hand-rolled hero-header variants found across the app (.cr-header, .gb-header, .adm-detail-header, .stu-header, ad-hoc .page-header copies). Usage (breadcrumb style, unchanged from the original component): {% include 'core/components/page_header.html' with title="Classes with Exams" subtitle="..." crumbs=crumbs %} Usage (icon-box style): {% include 'core/components/page_header.html' with title="Students" description="Manage enrolled students" icon="fa-user-graduate" actions=actions back_url=list_url %} Params: title (required) — page heading description (optional) — muted line under the title (alias: subtitle) breadcrumbs (optional) — list of {label, url} (alias: crumbs). Rendered in both styles. In icon-box style, if `title` is omitted the last crumb's label is used as the heading. icon (optional) — Font Awesome class (e.g. "fa-user-graduate"); presence of this param switches to icon-box style actions (optional) — list of dicts passed straight to components/button.html (label, url, variant, icon, type, size, disabled, attrs) back_url (optional) — renders a styled ".pw-page-back" button above the header (both styles). Pass a per-page fallback via {% url 'core:parent' as back_fallback %} + back_url=back_url|default:back_fallback so every page has one, even when the view sets no back_url. variant (optional) — "compact" reduces padding (icon-box style) Note: `description`/`subtitle` and `breadcrumbs`/`crumbs` are read with {% firstof %} rather than the `default` filter — `default:some_var` crashes if `some_var` was never passed in at all (not just falsy), since Django only tolerates missing variables when they're the base of a filter, not when they're a filter *argument*. Keep using {% firstof %} for any future optional-alias params here. {% endcomment %} {% if back_url %} Back{% endif %} {% if icon %}
