{% load core_extras %} {% comment %} Pinewood pagination — renders Django Page controls, preserving the current querystring (search/filter params) across page changes. Consolidates the ~15-line manual pagination loop duplicated across list pages. Usage (plain navigation): {% include 'core/components/pagination.html' with page_obj=page_obj %} Usage (htmx-swapped list, e.g. inside an htmx fragment whose parent page targets a container with search/filter results): {% include 'core/components/pagination.html' with page_obj=page_obj hx_target="#student-list-content" %} Params: page_obj (required) — a Django Page object preserve_query (optional) — set False to link with only `?page=N` and drop existing GET params (default: preserve them) hx_target (optional) — CSS selector; when given, page links render as hx-get/hx-target/data-loading instead of plain href navigation show_first_last (optional) — set False to hide the First/Last links (default: shown) numbered (optional) — render a windowed page-number list (Previous, current ±2, Next) instead of the First/Prev/ Page-X-of-Y/Next/Last controls above.
