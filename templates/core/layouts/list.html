{% extends 'core/base.html' %} {% comment %} List page pattern — a searchable/filterable table of records (drafted against templates/core/admission/list.html). Fixed region order: Header + action → Filters → Table (or its empty state) → Pagination → Extra. This layout only provides structure — fill each block with components from templates/core/components/ (page_header, toolbar, table_open/close, empty_state, pagination). See docs/UI_COMPONENTS.md. `layout_extra` is empty by default — use it for page-specific modals (many list pages have a create/edit/delete modal) or extra markup that doesn't fit the four named regions. It renders after pagination, but since modals are invisible until triggered, where they sit in the DOM doesn't matter.
